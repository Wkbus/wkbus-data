## 项目简介

文凯公交是一款面向日常通勤的 Android 实时公交应用，提供车辆站序、到站倒计时与沿途车辆状态，让候车更从容。

## 功能

- **实时到站预报**：线路上在途车辆的相对站序、预计到达时间与实时距离。
- **线路走向图**：基于 Jetpack Compose 构建，支持横向平滑全景轨道与纵向时间轴两种视图。
- **车队看板**：全线在途车辆一目了然，按距当前站距离排序，显示车牌、实时时速与准点状态。
- **站点详情**：大型公交枢纽站多物理站台一键切换、地铁换乘指引与全线综合到站看板。
- **极速搜索**：支持拼音字母及汉字模糊即时联想，快速定位线路与首末班方向。
- **收藏路线组**：把常用线路与换乘组合收进路线组，首页直接查看实时 ETA。
- **实时追踪**：前台服务追踪乘车进度，状态栏常驻进度与到站提醒通知，支持小米焦点通知与 OPPO 流体云。
- **乘车码快捷入口**：支付宝乘车码与云闪付乘车码一键唤起。
- **定时提醒**：按设定时间提醒乘车。
- **时刻表**：线路首末班与发车间隔查看。
- **地铁查看功能**：查看地铁线路、站点与首末班时刻表。
- **日本电车时刻表**：神户、大阪、京都、奈良、和歌山、姬路、广岛、福山 8 城电车时刻表，支持实时位置与发车榜。
- **多语言**：简体中文、繁體中文、English、日本語、维吾尔语、藏语。
- **深色模式**：遵循 Material 3 动态色彩与深色调优规范。

## 技术栈

| 模块 | 方案 |
| --- | --- |
| 编程语言 | Kotlin (Coroutines & StateFlow) |
| UI 架构 | Jetpack Compose, Material 3 Expressive |
| 导航组件 | AndroidX Navigation 3 |
| 网络层 | OkHttp 4, Kotlinx Serialization |
| 本地存储 | Jetpack DataStore Preferences |
| 构建系统 | Gradle Kotlin DSL, Version Catalogs |
